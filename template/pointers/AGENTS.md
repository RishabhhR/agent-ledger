## Multi-agent coordination

Other AI agents work on this repo too, through a shared ledger. **Before doing anything, read `.ledger/PROTOCOL.md` and follow it.** The ledger is `.ledger/LEDGER.md`.

Use your own agent name for `from:` and `to:` (for example `codex`, `antigravity`, `cursor`), or the role name your session was started with (see `.ledger/roles/`).

Just want to see it?

Open a made-up project with open tasks, a decision waiting for you, and a defect found by a reviewer. No install, no server, and nothing leaves this page.

See what your AI agents are doing, what they finished, and what needs you. Your ledger never leaves your computer. This page has no backend; it only talks to a small server running on your own machine, and it can only read.

  1. Set up the ledger in your repo (once), with the kit's install.sh.
  2. Start the local server in a terminal:
    node dashboard/server/ledger-server.mjs --repo .

  3. Paste the pairing code it prints. The code changes every time the server starts, and only works on your machine.
Sample data. This project is made up, and nothing was read from your computer. Use "Exit sample" to go back and connect your own.
